# Sports & games venue guides

Version 0.1.5 adds eight GTA VI activity guides. The map uses the "Sports & games" category for these venues.

| Activity | Venues | Gameplay evidence |
| --- | --- | --- |
| Pool | [The Rusty Anchor](https://map.gtadb.org/#VI,L325), [Delights Cabaret](https://map.gtadb.org/#VI,L629), [Jacob’s Tavern](https://map.gtadb.org/#VI,L3398) | [PowerPyx pool opponent guide](https://www.powerpyx.com/gta-6-all-pool-opponent-locations/) |
| Golf | [Leaf Links Golf Club](https://map.gtadb.org/#VI,L533) | [PowerPyx golf course guide](https://www.powerpyx.com/gta-6-all-golf-course-locations/) |
| Fitness | [Ajax Gym](https://map.gtadb.org/#VI,L1869), [Muscle Sands](https://map.gtadb.org/#VI,L1015), [Grand Majestic](https://map.gtadb.org/#VI,L240) | [PowerPyx gym guide](https://www.powerpyx.com/gta-6-all-gym-locations-fitness-centers/) |
| Arcade | [Jason’s House](https://map.gtadb.org/#VI,L266) in Chapter 1 | [PowerPyx console game guide](https://www.powerpyx.com/gta-6-all-video-game-locations/) and [Feng Shui walkthrough](https://www.powerpyx.com/gta-6-feng-shui-meet-cal-walkthrough/) |

Each guide uses the linked GTADB venue coordinate. Pin precision is venue-level. The Leaf Links and Grand Majestic pins cover the club grounds and property, respectively. GTADB flags the Delights coordinate as unconfirmed. The console pin applies to Jason’s Chapter 1 house in Key Lento. Availability changes with story progression.

Four of these coordinates are new to the activity catalogue. Four share a venue with an existing guide. Each activity has its own checklist entry. From The Rusty Anchor, the bundled road graph can route to Delights, Ajax Gym, Muscle Sands, Grand Majestic and Jason’s House. For Jacob’s Tavern or Leaf Links from that origin, the GPS displays a direct bearing.

These guides cover activity access and completion. Each guide links to its gameplay source and map evidence. See [map data credits and registration](MAP-DATA.md) for the coordinate frame and GTADB attribution.
