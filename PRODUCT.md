# GTA 6 Loot Map by theihtishaam

## Register

An open-source companion for GTA VI players finding rewards, planning an outing, and keeping a personal field journal.

## Platform

Web app served locally on a desktop, with layouts for narrow windows and touch input. The map is the main workspace.

## Design

Use a night-driving palette, warm amber controls and clearly differentiated pin symbols. Keep the terrain legible beneath the markers. Treat the source, precision, objective and completion state as part of each discovery. Players should be able to start exploring immediately, without creating an account or choosing a model.
